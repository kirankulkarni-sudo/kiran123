About, Open Source & Governance

Mission, data standards, verification rules and how the platform is governed.

Mission

The CivicTrack exists to make public development work inspectable. Citizens should be able to see what was promised, what was reported, what evidence supports those claims, and whether an independent review has confirmed the outcome.

We deliberately separate reported completion from verified completion. An upload is never treated as automatic proof.

Core Principles

  • Evidence over assertion
  • Clear status definitions
  • Audit trails for important changes
  • Public access to published records
  • Open-source code and transparent methodology

Open Source

The platform software is intended to be released under an open-source licence so that jurisdictions and civic technologists can inspect, adapt and improve it.

Verification Methodology

Verification uses project-type checklists. Typical evidence includes geo-tagged photographs, measurement sheets, completion certificates and site inspection notes. Reviewers record a decision (approve / reject / return) with a short public rationale.

Data Sources

Official department registers, authorized progress updates, and citizen-submitted issues (clearly labelled).

Update Frequency

Project records update when authorized users submit changes. Aggregate reports refresh daily in production.

Known Limitations

Coverage depends on participating departments. Incomplete data is disclosed rather than hidden.

Privacy, Security & Integrity

  • Role-based access control restricts officials to authorized records.
  • Personal contact details from issue reports are not published.
  • Uploaded files are validated and scanned; sensitive visual content is reviewed before public release where feasible.
  • Important project, evidence, verification and permission changes produce audit entries.
  • A correction and appeal process exists for disputed or inaccurate records.
